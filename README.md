# Четвёртая лаба по АК

Мой вариант: 

    lisp | risc | neum | hw | trap | port | pstr | cache | alg2

## Архитектура самого процессора + организация памяти

### Основные характеристики архитектуры:

1) Тип Архитектуры: RISK - все операция в АЛУ происходят исключительно внутри регистров. Команды имееют фиксированную длину
2) Модель памяти: Фон Нейман - коды инструкция, статические данные и динамический стек делят единое адресное пространство
3) RAM: 4096 слов по 32 бита

### Регистры:

К ниже перечисленным регистрам можно обратиться по машинным командам <br>

<b>R0</b> - Всегда является нулём, чтение даёт ноль, запись игнорируется <br> 
<b>R1-R10</b> - Регистры общего назначения. R1 используется для возврата результата функций <br> 
<b>SR/PS (R11)</b> - Регистр состояния, о его содержимом будет сказано ниже<br>
<b>SP (R12)</b> - Stack Pointer. Указывает на на последнюю ячейку в памяти <br>
<b>RES (R13)</b> - Резерв
<b>CR (R14)</b> - Регистр команд
<b>PC (R15)</b> - Хранит адрес текущей исполняемой инструкции <br>

### Memory Map

<b>0x0000 - 0x03E8</b> (1000 ячеек) : векторы прерывания + сегмент кода (например, инструкции, подпрограммы и точка входа) <br>
<b>0x03E9 - ...</b> : сегмент статических данных (будто строки или глобальные переменные) <br>
<b>... - 0x0FFF</b> (4095): стек, растущий сверху вниз по памяти <br>

### Формат кодирования инструкций

OPCODE + RD + RS2 + IMM / RS2 / ADDR <br>

Opcode (8 bit) - код операции
RD (4 bit) - регистр назначения
RS1 (4 bit) - первый регистр источник
Rs2 (16 bit) - второй регистр Rs2/константа/смещение/адрес перехода
